# Troubleshooting

## Bot Not Responding

Check:
- Permissions  
- Role hierarchy  
- Logging channel access  

## Anti‑Raid Not Triggering

Verify:
```
/security overview
```

Ensure:
- Thresholds are configured  
- Raid action is set  

## AutoMod Not Filtering

Check:
```
/automod list
```

Ensure rules are enabled.

## Verification Not Working

Verify:
- Verification channel exists  
- Bot can send messages  
- Captcha mode is configured
