---
title: "AutoMod"
description: "Автоматическая фильтрация небезопасного и деструктивного контента с настраиваемыми правилами для каждой гильдии."
---

Система AutoMod от Nightfall автоматически сканирует каждое сообщение на сервере и применяет настраиваемые политики контента — удаляет нарушения, предупреждает участников или эскалирует до киков и банов.

---

## Доступные фильтры

| Фильтр | Что обнаруживает |
|--------|----------------|
| `links` | Любой URL в сообщении (HTTP, HTTPS или голый домен) |
| `invites` | Ссылки‑приглашения на Discord‑серверы (`discord.gg/...`, `discord.com/invite/...`) |
| `caps` | Сообщения с чрезмерной долей заглавных букв |
| `words` | Сообщения, содержащие слова или фразы из пользовательского чёрного списка |
| `emojis` | Сообщения с чрезмерным количеством эмодзи |
| `duplicate` | Повторяющиеся идентичные или почти идентичные сообщения от одного пользователя |
| `mentions` | Сообщения, которые пингуют чрезмерное количество пользователей или ролей |

---

## Действия

Каждое правило можно настроить с одним из следующих действий:

| Действие | Эффект |
|--------|--------|
| `delete` | Нарушающее сообщение молча удаляется |
| `warn` | Сообщение удалено + записано формальное предупреждение + участнику отправлено DM |
| `timeout` | Сообщение удалено + предупреждение + участник временно замьючен (10 минут) |
| `kick` | Сообщение удалено + участник кикнут с сервера |
| `ban` | Сообщение удалено + участник получает постоянный бан |

---

## Приоритет правил

Когда сообщение соответствует нескольким правилам, применяется только правило с наивысшим приоритетом:

```
1. invites
2. links
3. words
4. caps
5. mentions
6. emojis
7. duplicate
```

---

## Подробности фильтров

### Links

Обнаруживает любой URL в сообщении. Полезно для предотвращения размещения фишинговых ссылок спам‑ботами или для ограничения каналов только текстом.

### Invites

Обнаруживает конкретно ссылки‑приглашения на Discord‑серверы. Используйте это, чтобы участники не рекламировали другие серверы, но по‑прежнему могли делиться другими URL.

### Caps

Обнаруживает сообщения с чрезмерной долей заглавных букв. Настройте пороговый процент командой `/automod config rule:caps value:70` (по умолчанию: 70%).

Сообщения короче 8 символов игнорируются во избежание ложных срабатываний на коротких восклицаниях.

### Words

Обнаруживает сообщения, содержащие слова или фразы из пользовательского чёрного списка. Регистр не учитывается.

**Пример:**
```
/automod config rule:words value:spam,advertisement,phishingdomain.com
```

### Emojis

Обнаруживает сообщения с чрезмерным количеством эмодзи (стандартных Unicode и пользовательских Discord). Порог по умолчанию: 15 эмодзи.

### Duplicate

Обнаруживает повторяющиеся идентичные или почти идентичные сообщения от одного пользователя за короткий период. По умолчанию: 3 одинаковых сообщения за 30 секунд.

### Mentions

Обнаруживает сообщения, которые пингуют чрезмерное количество пользователей или ролей в одном сообщении. Порог по умолчанию: 8 упоминаний.

---

## Пример конфигурации

Защита публичного сервера от типичных угроз:

```
# Блокировать ссылки‑приглашения с предупреждением
/automod enable rule:invites action:warn

# Блокировать внешние ссылки с тихим удалением
/automod enable rule:links action:delete

# Помечать чрезмерные заглавные буквы с удалением
/automod enable rule:caps action:delete
/automod config rule:caps value:80

# Пользовательский чёрный список слов
/automod enable rule:words action:warn
/automod config rule:words value:badword,spamphrase,phishingdomain.com

# Защита от массовых упоминаний
/automod enable rule:mentions action:timeout
/automod config rule:mentions value:6

# Спам повторяющимися сообщениями
/automod enable rule:duplicate action:warn
/automod config rule:duplicate value:3
```

## Интеграция с белым списком

Пользователи и роли, добавленные в белый список гильдии, обходят все проверки AutoMod. Это полезно для персонала, который может законно публиковать ссылки или приглашения.

Управляйте исключениями командой `/whitelist`. См. [Справку по белому списку](/commands/whitelist).

---

## Интеграция с Anti‑Nuke / Anti‑Raid

AutoMod и системы обнаружения безопасности **независимы**:

- AutoMod обрабатывает нарушения на уровне отдельных сообщений
- Anti‑Raid обрабатывает шаблоны всплесков вступлений
- Anti‑Nuke обрабатывает структурные атаки (удаления каналов / ролей, массовые баны)

Одиночное событие, вызывающее оба (например, массовое упоминание во время рейда), одновременно активирует и действие AutoMod, и оповещение безопасности.
