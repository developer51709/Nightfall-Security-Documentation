Nightfall предоставляет несколько независимых уровней защиты, каждый из которых нацелен на отдельный класс угроз. Они бесшовно работают вместе — одно событие может одновременно активировать несколько уровней.

## Как обнаруживаются угрозы

Nightfall использует **счётчики частоты со скользящим окном** для отслеживания частоты событий в реальном времени. Счётчик для каждой гильдии отслеживает, сколько событий каждого типа (удаления каналов, удаления ролей, вступления, баны, упоминания) произошло за последние 60 секунд. Когда счётчик превышает настроенный порог, немедленно срабатывает оповещение.

Такой подход:
- **Быстрый** — никаких накладных расходов на базу данных на каждое событие; счётчики находятся в памяти
- **Точный** — настоящее 60‑секундное скользящее окно, а не фиксированный временной интервал
- **Для каждой гильдии** — у каждого сервера свои независимые счётчики и пороги

## Карточки оповещений

Когда порог превышен, Nightfall публикует форматированное оповещение в вашем настроенном канале оповещений:

```
🛡️  Security Alert — ANTI_RAID
────────────────────────────────────────
Join surge detected: 14 joins in the last 60 seconds.
Threshold: 10 per minute.

👥  Actor:    @username (123456789)
⏰  Detected: just now

─  Nightfall Security  •  Severity: HIGH  •  Defensive mode only
```

Уровни серьёзности:

| Уровень | Значение |
|-------|---------|
| **Low** | Незначительная аномалия — информационно |
| **Medium** | Подозрительная активность |
| **High** | Обнаружена активная угроза |
| **Critical** | Серьёзная скоординированная атака |

## Только защитная модель

Nightfall разработан исключительно для **защиты**, никогда для причинения вреда:

- ✅ Оповещение модераторов через настроенный канал оповещений
- ✅ Выполнение настраиваемых автоматических действий (kick, ban) при обнаружении угроз
- ✅ Задействование мягких блокировок для приостановки отслеживания деструктивных действий
- ❌ Никогда не инициирует наступательные действия против других серверов или пользователей
- ❌ Никогда не выполняет действий сверх того, что администратор сервера явно настроил

## Пресеты порогов

Мастер `/setup` предлагает три пресета порогов в качестве отправной точки:

| Пресет | Вступл./мин | Удаления каналов/мин | Удаления ролей/мин | Баны/мин | Упоминания |
|--------|-----------|--------------------|-----------------|---------|---------| 
| **Strict** | 5 | 2 | 2 | 3 | 5 |
| **Balanced** | 10 | 3 | 3 | 5 | 8 |
| **Relaxed** | 20 | 6 | 6 | 10 | 15 |

Все пороги можно точно настроить в любое время командой `/security config`. См. [Справочник команд безопасности](/commands/security) для всех доступных опций.

---

## Белый список

Доверенных администраторов, ботов или роли можно освободить от всего обнаружения. Действия сущностей из белого списка не увеличивают ни один счётчик частоты.

Управляйте исключениями командой `/whitelist`. См. [Справку по белому списку](/commands/whitelist) для требований к разрешениям и использования.

<Warning>
  Внесение в белый список — это мощный инструмент: занесённая в белый список роль освобождает каждого участника, который ею обладает. Избегайте занесения в белый список широких ролей, иначе вы фактически отключите защиту для этих участников.
</Warning>
