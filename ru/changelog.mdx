## v2.1.0 — текущая

### Новые возможности

**Support Bot** (вторичный бот)

- Система тикетов с трёхшаговым процессом создания, 9 категориями и приватными каналами для каждого пользователя
- Панель управления персоналом: claim, release, transfer, status и close
- Постоянные панели FAQ и правил

**Переработанный `/whitelist`**

- Заменил предыдущие подкоманды `/whitelist add` единой интерактивной панелью
- Кнопки Add User / Add Role / Remove открывают приватные эфемерные пикеры
- Строгая модель разрешений на редактирование: владелец сервера или роль Administrator, расположенная выше роли бота — перепроверяется при каждом изменении

**Партнёрские выплаты**

- Партнёры теперь могут запрашивать выплаты прямо из Discord через команду ботов `/affiliate payout`
- Выплаты можно запрашивать в различных криптовалютах и обрабатываются напрямую через интеграцию OxaPay

### Исправления

- **Приложения, принадлежащие команде** — авторизация владельца теперь корректно определяет уполномоченного владельца для Discord‑приложений, принадлежащих команде, предотвращая блокировки
- **Глобальное подавление упоминаний** — все хелперы ответов и компонентов теперь стабильно подавляют пинги `@everyone`, ролей и пользователей
- **Тикеты поддержки** — устранена ошибка на шаге подтверждения при закрытии; описания проблем участников теперь публикуются в канале тикета; счётчик тикетов устойчив к переподключениям; дубликаты тикетов перепроверяются перед созданием канала

### Улучшения

- Снижена цена премиум‑подписки с `$9.99 USD` → `$6.00 USD`
- Снижена минимальная сумма партнёрской выплаты с `$10.00 USD` → `$1.00 USD`
- Снижено требование для партнёрской выплаты с тира Diamond → тир Gold

## v2.0.0

### Новые возможности

**Интерактивный мастер настройки** (`/setup`)
- Многошаговое пошаговое сопровождение для новых серверов
- Охватывает выбор канала оповещений, пресет уровня защиты и переключение функций
- Заканчивается предложением обновления до Premium

**Система партнёрских пробных периодов**
- Партнёрские коды теперь предоставляют **7‑дневный бесплатный пробный период** вместо немедленного полного Premium
- Один пробный период на гильдию навсегда — принудительно применяется на уровне базы данных
- DM со скидкой после пробного периода отправляется автоматически планировщиком (20% на первый месяц)

**Группа команд `/affiliate`**
- `/affiliate code` — просмотр вашего кода, инструкции по распространению и текущий тир
- `/affiliate stats` — полная панель аналитики (пробники, конверсии, коэффициент, прогресс по тирам)
- `/affiliate perks` — лестница тиров с отображением закрытых / открытых привилегий
- `/affiliate leaderboard` — топ партнёров по конверсиям (только для владельцев бота)
- Пять партнёрских тиров: Partner → Bronze → Silver → Gold → Diamond

**Отслеживание конверсий**
- Гильдии, купившие платный Premium после партнёрского пробного периода, автоматически помечаются как конвертированные

**Поддержка нескольких владельцев**
- `/owner add` / `/owner remove` — предоставление или отзыв статуса владельца бота для дополнительных пользователей

**Типы премиум‑кодов**
- `onetime` — одна гильдия, затем отключается
- `multiuse` — можно активировать до N гильдий
- `affiliate` — неограниченное использование, отслеживает реферера, предоставляет 7‑дневный пробник

### Функции безопасности

- **Anti‑Nuke** — обнаружение частоты по скользящему окну для удалений каналов / ролей и массовых банов
- **Anti‑Raid** — обнаружение всплесков вступлений и наплыва новых аккаунтов
- **Массовое упоминание** — обнаружение флуда упоминаний в одном сообщении
- **Белый список** — исключения пользователей / ролей для каждой гильдии
- **AutoMod** — фильтры ссылок, приглашений, заглавных букв, слов, эмодзи, дубликатов и упоминаний
- **Модерация** — ban, kick, warn, timeout с форматированными карточками действий
- **Верификация** — капча изображения с постоянной кнопкой панели
- **Логирование** — полный журнал аудита по участникам, сообщениям, каналам, ролям, голосу и событиям сервера
