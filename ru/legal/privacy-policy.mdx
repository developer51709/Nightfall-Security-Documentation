## 1. Введение

Эта Политика конфиденциальности объясняет, какие данные Nightfall Security («Бот», «мы», «нас») собирает, зачем мы их собираем, как они хранятся и каковы ваши права в отношении этих данных.

Добавляя Бота на свой Discord‑сервер или взаимодействуя с ним, вы соглашаетесь с практикой обработки данных, описанной в настоящей Политике. Если вы эксплуатируете самохостируемый экземпляр Nightfall Security, вы являетесь контроллером данных для своих пользователей и должны публиковать собственную политику конфиденциальности.

## 2. Какие данные мы собираем

### 2.1 Данные сервера (гильдии)

| Данные | Цель | Хранятся |
|------|---------|--------|
| Guild ID | Идентификация вашего сервера для настроек каждой гильдии | Да, постоянно |
| Имя гильдии | Упоминается в журналах и DM‑уведомлениях | Нет — извлекается только во время выполнения |
| Owner ID | DM о подписке и напоминаниях | Да, в записях премиум‑подписок |
| ID канала оповещений | Публикация оповещений безопасности | Да, в настройках гильдии |
| Пороги безопасности | Пользовательская конфигурация обнаружения | Да, в настройках гильдии |
| Записи журнала аудита | Определение исполнителя для событий безопасности | Нет — извлекается во время выполнения, не хранится |

### 2.2 Данные участников / пользователей

| Данные | Цель | Хранятся |
|------|---------|--------|
| User ID | История модерации, предупреждения, права владения, партнёрские записи | Да |
| Имя пользователя / отображаемое имя | Упоминается в сообщениях журнала | Нет — извлекается только во время выполнения |
| Содержимое сообщений | Оценка правил AutoMod | Нет — оценивается в памяти, никогда не сохраняется |
| Длина сообщения | Статистическое обнаружение спама | Да (только длина, не содержимое) |
| Дата создания аккаунта | Обнаружение рейдов новых аккаунтов | Нет — извлекается только во время выполнения |
| Ответы на верификацию | Задача с капчей изображения | Временно — удаляются после верификации (макс. 10 минут) |

### 2.3 Данные модерации

| Данные | Цель | Хранятся |
|------|---------|--------|
| Записи предупреждений (гильдия, пользователь, модератор, причина, временная метка) | История модерации и след аудита | Да, постоянно |
| Записи событий безопасности (тип угрозы, серьёзность, ID исполнителя, детали) | Журнал аудита безопасности | Да, 90 дней |

### 2.4 Платёжные данные

Nightfall Security **не** обрабатывает платежи напрямую. Платежи обрабатываются OxaPay, сторонним провайдером. Мы храним:

| Данные | Цель | Хранятся |
|------|---------|--------|
| ID отслеживания счёта OxaPay | Связывание платежа с подпиской | Да, в записях премиум‑подписки |
| Истечение подписки | Контроль доступа к функциям | Да, в записях премиум‑подписки |

Мы не храним номера банковских карт, адреса криптокошельков или какие‑либо платёжные реквизиты. Подробнее о практиках обработки данных см. в [Политике конфиденциальности OxaPay](https://oxapay.com/privacy).

### 2.5 Партнёрские данные

| Данные | Цель | Хранятся |
|------|---------|--------|
| ID партнёрского пользователя | Зачисление рефералов и отслеживание тиров | Да, в партнёрских записях |
| Начало / истечение пробного периода | Управление жизненным циклом пробного периода | Да, в партнёрских записях |
| Статус конверсии | Партнёрская аналитика | Да, в партнёрских записях |
| Статус отправки DM со скидкой | Предотвращение дубликатов DM | Да, в партнёрских записях |

### 2.6 Данные тикетов поддержки (support bot)

Опциональный **Support Bot** обеспечивает работу сервера сообществ­ной поддержки проекта. Он актуален только если вы вступили на этот сервер и открыли тикет поддержки. Когда вы это делаете:

| Данные | Цель | Хранятся |
|------|---------|--------|
| Ваш Discord user ID | Связывание тикета с вами и ограничение доступа к каналу | Да — в метаданных темы канала тикета |
| Категория и статус тикета | Маршрутизация и отслеживание вашего запроса | Да — в метаданных темы канала тикета |
| Ваше описание проблемы и сообщения | Предоставление поддержки | Да — как сообщения в приватном канале тикета, сохраняются до удаления канала |
| ID назначенного сотрудника | Отслеживание владения тикетом | Да — в метаданных темы канала тикета |

Содержимое тикетов находится внутри самого канала Discord (не в базе данных бота) и видно только вам и персоналу поддержки. Не делитесь конфиденциальными учётными данными (пароли, платёжные данные, токены) в тикете. Персонал поддержки может удалять или архивировать каналы тикетов по своему усмотрению.

## 3. Что мы НЕ собираем

- **Содержимое сообщений** — сообщения оцениваются в памяти для правил AutoMod и немедленно отбрасываются. Никакой текст сообщений не хранится. *(Исключение: если вы открываете тикет поддержки, сообщения, отправленные вами в этот канал тикета, сохраняются как сообщения Discord до удаления канала — см. §2.6.)*
- **Голосовые данные** — мы регистрируем события изменения голосового состояния (вход/выход/мут) для целей аудита, но не записываем аудио.
- **Прямые сообщения** — Бот может отправлять DM (напоминания, карточки оформления заказа, предложения скидок), но не читает и не хранит входящие DM.
- **Адреса электронной почты** — у нас нет системы аккаунтов; идентичность полностью основана на Discord user ID.
- **Настоящие имена или адреса** — мы не собираем никакой персонально идентифицируемой информации, кроме Discord user ID и guild ID.
- **Финансовая информация** — платёжные данные обрабатываются исключительно OxaPay.

## 4. Как мы используем данные

| Цель | Используемые данные | Правовое основание |
|---------|-----------|-------------|
| Обнаружение угроз безопасности и оповещение о них | Настройки гильдии, счётчики событий (в памяти) | Законный интерес (безопасность сервера) |
| История модерации и предупреждения | User ID, ID модератора, причина, временная метка | Законный интерес (безопасность сервера) |
| Предоставление премиум‑функций | Guild ID, истечение подписки | Исполнение договора |
| Отправка DM с напоминаниями об истечении | Owner ID, истечение подписки | Исполнение договора |
| Отслеживание партнёрской программы | Партнёрский код, guild ID, статус конверсии | Законный интерес (работа программы) |
| Отправка DM со скидкой после пробного периода | ID владельца гильдии | Законный интерес (коммерческая коммуникация) |
| Обнаружение спама / частоты сообщений | Длина сообщения, ID автора, временная метка | Законный интерес (безопасность сервера) |
| Обработка запросов поддержки | User ID тикета, категория, статус и сообщения | Законный интерес (предоставление поддержки) |

## 5. Хранение данных

| Данные | Срок хранения |
|------|----------------|
| Настройки гильдии | Пока сервер не удалит Бота или не запросит удаление |
| Предупреждения | Постоянно (для целостности аудита) |
| События безопасности | 90 дней (авто‑очистка) |
| Статистика сообщений | 30 дней (авто‑очистка) |
| Премиум‑подписки | До 7 дней после истечения (авто‑очистка) |
| Премиум‑коды | До удаления владельцем бота |
| Партнёрские пробные периоды | Постоянно (для соблюдения правила один‑пробник‑на‑гильдию) |
| Сессии верификации | 10 минут (авто‑истечение) |
| События AutoMod | 30 дней (авто‑очистка) |
| Каналы тикетов поддержки и их содержимое | До закрытия и удаления канала персоналом поддержки |

## 6. Передача данных

Мы не продаём, не сдаём в аренду и не передаём ваши данные третьим сторонам, за исключением:

**6.1 Discord Inc.** — Бот взаимодействует с API Discord для функционирования. К любым данным, передаваемым через их платформу, применяется [Политика конфиденциальности](https://discord.com/privacy) Discord.

**6.2 OxaPay** — когда вы инициируете покупку премиум, ваша платёжная информация отправляется в OxaPay. Мы передаём только сумму счёта, описание и внутренний ID заказа.

**6.3 Законные требования** — мы можем раскрыть данные, если это требуется по закону, решению суда или для защиты прав и безопасности операторов Бота или других лиц.

## 7. Безопасность данных

Все данные хранятся безопасно с использованием:

- Контроля доступа на уровне приложения, обеспечивающего безопасную сериализацию всех записей
- Безопасности одновременного чтения во время операций записи
- Отсутствия публичного API данных

Мы применяем разумные технические меры для защиты ваших данных. Однако ни одна система не является идеально безопасной. Вы должны обеспечить, чтобы ваша среда хостинга имела соответствующий контроль доступа и шифрование диска при обработке конфиденциальных данных сервера.

## 8. Ваши права

### Для администраторов серверов

Как администратор, пригласивший Бота, вы можете:

- **Просматривать** сохранённые настройки вашей гильдии через `/security overview`, `/automod status` и `/logging status`
- **Изменять** настройки в любое время через соответствующие команды
- **Удалить** данные вашей гильдии, удалив Бота с сервера и связавшись с нами для ручного запроса на удаление данных

### Для участников серверов

Как участник сервера, чьи данные могут храниться (например, запись о предупреждении):

- Вы можете запросить доступ к своим персональным данным, их исправление или удаление, связавшись с администратором сервера, который может подать запрос на удаление от вашего имени
- Discord user ID считаются псевдонимными идентификаторами, не являющимися напрямую идентифицирующими персональными данными по большинству рамок, но мы уважаем разумные запросы на удаление

### Реализация прав

Чтобы воспользоваться любыми правами на данные, свяжитесь с нами через официальный сервер поддержки. Мы ответим в течение 30 дней.

## 9. Конфиденциальность детей

Бот не предназначен для использования лицами младше 13 лет, что соответствует минимальному возрасту, требуемому Discord. Если вы считаете, что ребёнок младше 13 лет взаимодействовал с Ботом таким образом, который привёл к сбору данных, свяжитесь с нами для немедленного удаления.
