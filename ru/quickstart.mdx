Nightfall Security разработан так, чтобы быть простым в настройке и при этом обеспечивать профессиональную многоуровневую защиту для Discord‑сообществ любого размера. Это руководство по быстрому старту проведёт вас от нуля до полностью настроенной установки Nightfall всего за несколько минут.

## Предварительные требования

Перед началом убедитесь, что у вас есть:

- **Права администратора** на сервере, который вы хотите защитить
- Discord‑сервер, где будет установлен Nightfall
- Базовое знакомство с системой ролей и каналов Discord (рекомендуется)

## Начало работы

<Steps>
  <Step title="Пригласите Nightfall Security">
    Добавьте Nightfall на свой сервер, используя официальную ссылку приглашения:

    **[Пригласить Nightfall Security](https://discord.com/oauth2/authorize?client_id=1528576288938266694)**

    Nightfall требует основных разрешений, таких как управление ролями, каналами, банами и историей сообщений, чтобы обеспечить полную защиту. Предоставьте все запрошенные разрешения для полного покрытия.

    <Tip>
      Роль Nightfall должна располагаться **выше** любых ролей, которыми она должна управлять (например, вашей роли проверенного участника). Вы можете настроить порядок ролей в **Настройки сервера → Роли**.
    </Tip>
  </Step>

  <Step title="Запустите мастер настройки">
    Как только Nightfall окажется на вашем сервере, запустите руководимый процесс настройки:

    ```
    /setup
    ```

    Мастер проведёт вас через:

    - **Alert Channel** — где публикуются оповещения безопасности
    - **Protection Level** — выберите пороги Strict, Balanced или Relaxed
    - **Anti‑Nuke** — переключение защиты от деструктивных действий администраторов
    - **Verification** — переключение гейта входа участников

    Каждый шаг включает рекомендуемые значения по умолчанию, чтобы обеспечить надёжную защиту с самого начала. Вы можете вернуться и настроить любые параметры позже.
  </Step>

  <Step title="Проверьте установку">
    После настройки убедитесь, что Nightfall активен и защищает ваш сервер:

    ```
    /security overview
    ```

    Эта команда отображает:
    - Активные системы защиты и их пороги
    - Недавние оповещения безопасности
    - Рекомендуемые улучшения конфигурации
  </Step>

  <Step title="Настройте журналирование (опционально)">
    Настройте каналы журнала аудита, чтобы иметь полный отчёт об активности сервера:

    ```
    /logging set category:members channel:#member-logs
    /logging set category:moderation channel:#mod-audit
    /logging set category:security channel:#security-log
    ```

    См. [Справочник команд журналирования](/commands/logging) для всех доступных категорий.
  </Step>

  <Step title="Включите верификацию (опционально)">
    Добавьте гейт входа участников, чтобы блокировать бот‑рейды до их начала:

    1. Создайте канал `#verify-here`, который `@everyone` может видеть, но не может отправлять сообщения, и который скрывает все остальные каналы
    2. Создайте роль `@Verified`, которая предоставляет полный доступ к серверу
    3. Запустите `/verification panel` для настройки роли и включения капчи
    4. Запустите `/verification post channel:#verify-here` для публикации постоянной кнопки Verify

    Полные подробности см. в [Верификации](/verification).
  </Step>
</Steps>

## Что защищено после настройки?

После завершения работы мастера Nightfall активно отслеживает ваш сервер на:

| Угроза | Защита |
|--------|-----------|
| Массовые удаления каналов / ролей | Anti‑Nuke |
| Массовые баны скомпрометированными админами | Anti‑Nuke |
| Всплески вступлений и потоки ботов | Anti‑Raid |
| Кластеры новых / подозрительных аккаунтов | Anti‑Raid |
| Спам‑ссылки и реклама приглашений | AutoMod |
| Массовые упоминания | AutoMod + Security |
