Партнёрская программа Nightfall позволяет одобренным партнёрам получать признание и привилегии за приглашение Discord‑серверов на премиум‑тариф бота. Партнёры делятся уникальным кодом; каждый сервер, активирующий код, получает 7‑дневный бесплатный пробный период, а серверы, перешедшие на платный Premium, засчитываются в тир партнёра.

---

## Как это работает

<Steps>
  <Step title="Получите свой код">
    Партнёрские коды выдаются администраторами бота Nightfall. После одобрения вы получаете уникальный код для распространения.
  </Step>

  <Step title="Поделитесь кодом">
    Поделитесь своим кодом с администраторами Discord‑серверов. Они активируют его командой:

    ```
    /premium redeem code:YOUR-AFFILIATE-CODE
    ```
  </Step>

  <Step title="Активируется пробный период">
    Сервер немедленно получает **7‑дневный бесплатный пробный период** Nightfall Premium. Каждый сервер может активировать партнёрский пробный период только один раз.
  </Step>

  <Step title="Отслеживайте конверсии">
    Следите за пробными периодами, конверсиями и прогрессом по тирам с помощью `/affiliate stats`.
  </Step>

  <Step title="Получайте привилегии">
    По мере накопления конверсий вы продвигаетесь по тирам и открываете доступ к признанию, приоритетной поддержке и праву на выплаты.
  </Step>
</Steps>

## Система тиров

| Тир | Требуется конверсий | Право на выплаты | Привилегии |
|------|---------------------|:---------------:|-------|
| **Partner** | 0 | ❌ | Начало отслеживания — делитесь кодом и получайте конверсии |
| **Bronze** | 1+ | ❌ | Значок партнёра в `/affiliate stats` |
| **Silver** | 3+ | ❌ | Упоминание в приоритетной поддержке + пользовательская аналитика |
| **Gold** | 7+ | ✅ | Право на долю от дохода + кошелёк для выплат + приоритетная поддержка |
| **Diamond** | 15+ | ✅ | Право на партнёрский спотлайт + все привилегии Gold |

Тиры рассчитываются в реальном времени по количеству конверсий — ручное присвоение тира не требуется.

## Аналитика

Просмотрите полную панель аналитики командой:

```
/affiliate stats
```

| Метрика | Описание |
|--------|-------------|
| Всего пробных периодов | Гильдии, активировавшие ваш код |
| Активные пробные периоды | Пробные периоды, идущие в данный момент |
| Ожидающие конверсии | Пробные периоды истекли, скидка отправлена, ожидается покупка |
| Конверсии | Гильдии, купившие Premium после пробного периода |
| Коэффициент конверсии | `конверсии ÷ всего_пробных_периодов × 100` |

---

## Система выплат

Партнёры уровня **Gold и выше** (7+ конверсий) могут зарегистрировать криптовалютный кошелёк для получения выплат.

```
/affiliate payout
```

Используйте кнопку **Set / Update Wallet** в панели, чтобы ввести адрес кошелька и сеть. Поддерживаемые сети: Bitcoin (BTC), Ethereum (ETH), Solana (SOL), USDT‑TRC20, USDT‑ERC20, USDC‑ERC20, Litecoin (LTC) и другие.

Выплаты обрабатываются командой Nightfall по скользящему расписанию для подходящих партнёров.

---

## Скидка после пробного периода

Когда пробный период истекает, а сервер не переходит на платный Premium, Nightfall автоматически отправляет владельцу сервера **одноразовое DM** с предложением скидки (20% на первый месяц). Если владелец сервера позже совершит покупку, конверсия зачисляется на ваш счёт.

## Команды

| Команда | Описание |
|---------|-------------|
| `/affiliate code` | Просмотр вашего кода, инструкции по распространению и текущий тир |
| `/affiliate stats` | Полная панель аналитики — пробные периоды, конверсии, коэффициент и прогресс по тирам |
| `/affiliate perks` | Просмотр лестницы тиров с индикаторами закрытых и открытых привилегий |
| `/affiliate payout` | Регистрация или обновление кошелька для выплат (уровень Gold и выше) |
| `/affiliate leaderboard` | Топ партнёров, ранжированных по конверсиям (видно администраторам бота) |

## Как стать партнёром

Партнёрские коды выдаются зарегистрированными администраторами бота Nightfall. Чтобы подать заявку:

1. Вступите в [официальный сервер поддержки](https://discord.gg/CXzX38Z7J9)
2. Свяжитесь с командой, чтобы выразить заинтересованность
3. Если заявка одобрена, ваш код активируется немедленно
4. Достигните **тира Gold** (7+ конверсий), чтобы разблокировать регистрацию кошелька

## Правила

- **Достоверное представление** — партнёры обязаны честно представлять Nightfall и пробное предложение. Вводящая в заблуждение или обманная реклама запрещена.
- **Никакого мошенничества** — создание фальшивых активаций пробного периода, координация ложных конверсий или любое другое партнёрское мошенничество влечёт немедленное удаление и отмену ожидающих привилегий.
- **Собственность кода** — партнёрские коды остаются собственностью администраторов бота Nightfall и могут быть отозваны в любое время.
