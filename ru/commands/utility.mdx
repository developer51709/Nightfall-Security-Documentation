Утилитарные команды предоставляют общую информацию о боте и его настройки. Большинство доступны всем участникам сервера.

---

## Slash‑команды

### `/ping`

Проверить задержку gateway бота.

**Ответ:** задержка в миллисекундах с цветным индикатором состояния:
- 🟢 **Зелёный** — менее 150 мс (отлично)
- 🟡 **Жёлтый** — 150–300 мс (приемлемо)
- 🔴 **Красный** — более 300 мс (ухудшено)

**Prefix‑эквивалент:** `!ping`

---

### `/status`

Отобразить полную информацию о состоянии бота.

**Показывает:**
- Аптайм бота
- Задержку gateway
- Количество гильдий и общее число участников
- Количество активных воркеров событий
- Количество премиум‑подписок

**Prefix‑эквивалент:** `!status`

---

### `/info`

Отобразить информацию о текущем сервере.

**Показывает:**
- Имя сервера, ID и иконку
- Упоминание владельца
- Количество участников (всего, людей, ботов)
- Количество каналов и ролей
- Дату создания сервера и его возраст
- Уровень верификации и уровень буста
- Активные функции безопасности (Anti‑Nuke, Верификация)
- Статус Premium

**Prefix‑эквивалент:** `!info`

---

### `/help`

Отобразить полный справочник команд, организованный по категориям.

Перечисляет все команды, сгруппированные по: Security, Moderation, AutoMod, Logging, Verification, Premium, Affiliate, Utility и Owner (только для владельцев).

**Prefix‑эквивалент:** `!help`

---

### `/setprefix`

Изменить префикс команд бота для этого сервера.

| Опция | Тип | Обязательно | Описание |
|--------|------|:--------:|-------------|
| `prefix` | String | ✅ | Новый префикс (1–5 символов) |

**Требуемое разрешение:** Administrator

Новый префикс сохраняется и применяется немедленно. Упоминание бота (`@Nightfall`) всегда работает как префикс независимо от пользовательской настройки.

**Prefix‑эквивалент:** `!setprefix <new>`

---

### `/setup`

Запустить интерактивный мастер настройки для сопровождения нового сервера.

Мастер проведёт вас через:
1. **Alert Channel** — куда публикуются оповещения безопасности
2. **Protection Level** — пресеты порогов Strict, Balanced или Relaxed
3. **Feature Toggles** — Anti‑Nuke, Верификация
4. **Completion** — сводка и опциональное предложение обновления до Premium

---

## Prefix‑команды

Все prefix‑команды используют настроенный на сервере префикс (по умолчанию: `!`). Упоминание бота работает вместо префикса в любое время.

| Команда | Описание |
|---------|-------------|
| `!ping` | Задержка gateway |
| `!status` | Состояние бота |
| `!info` | Информация о сервере |
| `!help` | Список команд |
| `!setprefix <prefix>` | Изменить префикс (только для админа) |

---

## Ответ на упоминание

Пинг бота без ничего другого (`@Nightfall`) вызывает карточку с быстрой информацией, показывающую:

- Текущий префикс
- Задержку gateway
- Количество гильдий
- Сводку активных защит
- Основные быстрые команды

---

## Как узнать свой префикс

Если вы забыли пользовательский префикс, всегда используйте упоминание бота:

```
@Nightfall help
@Nightfall ping
```
