---
title: "/automod"
description: "Настройка правил автоматической фильтрации сообщений — включение, отключение и точная настройка каждого фильтра независимо."
---

Группа команд `/automod` позволяет администраторам настраивать автоматическую фильтрацию сообщений Nightfall. Каждое правило можно независимо включать или отключать и настраивать со своим собственным действием и порогом.

Все команды `/automod` требуют разрешения **Administrator** и доступны только на сервере.

---

## Доступные фильтры

| Фильтр | Что обнаруживает |
|--------|----------------|
| `links` | Любой URL в сообщении |
| `invites` | Ссылки‑приглашения Discord (`discord.gg/...`) |
| `caps` | Сообщения с чрезмерной долей заглавных букв |
| `words` | Сообщения, содержащие слова из пользовательского чёрного списка |
| `duplicate` | Идентичные или почти идентичные сообщения, повторно отправленные одним пользователем |
| `emojis` | Сообщения с чрезмерным количеством эмодзи |
| `mentions` | Сообщения, пингующие чрезмерное количество пользователей или ролей |

---

## Команды

### `/automod enable`

Включить правило фильтра с указанным действием.

| Опция | Тип | Обязательно | Описание |
|--------|------|:--------:|-------------|
| `rule` | Choice | ✅ | Фильтр для включения |
| `action` | Choice | ✅ | Что делать при срабатывании правила |

**Доступные действия:**

| Действие | Описание |
|--------|-------------|
| `delete` | Молча удалить нарушающее сообщение |
| `warn` | Удалить + выдать формальное предупреждение автору |
| `timeout` | Удалить + предупредить + временно замьютить автора |
| `kick` | Удалить + кикнуть автора |
| `ban` | Удалить + забанить автора |

---

### `/automod disable`

Отключить активное правило фильтра.

| Опция | Тип | Обязательно | Описание |
|--------|------|:--------:|-------------|
| `rule` | Choice | ✅ | Фильтр для отключения |

---

### `/automod config`

Настройка параметров, специфичных для правила (например, пользовательский список слов, порог заглавных букв).

| Опция | Тип | Обязательно | Описание |
|--------|------|:--------:|-------------|
| `rule` | Choice | ✅ | Фильтр для настройки |
| `value` | String | ✅ | Значение конфигурации (формат зависит от правила) |

**Форматы для конкретных правил:**

| Правило | Формат `value` | Пример |
|------|---------------|---------|
| `caps` | Целое число (процент порога) | `70` — помечать, если 70%+ букв заглавные |
| `words` | Список слов через запятую | `badword1,badword2,badword3` |
| `duplicate` | Целое число (порог повторов) | `3` — помечать после 3 идентичных сообщений за 30 секунд |
| `emojis` | Целое число (порог количества эмодзи) | `15` — помечать при 15 или более эмодзи |
| `mentions` | Целое число (порог количества упоминаний) | `5` — помечать при 5 или более пингов |

---

### `/automod status`

Отобразить текущую конфигурацию AutoMod для этого сервера — таблицу всех правил с их состоянием (включено/выключено), действием и любой дополнительной конфигурацией.

---

### `/automod stats`

*(Функция Premium)* Просмотр статистики срабатываний AutoMod для сервера.

Показывает количество срабатываний по каждому правилу за последние 7 и 30 дней, топ каналов‑нарушителей и топ пользователей‑нарушителей.

---

## Порядок оценки правил

Когда сообщение соответствует нескольким правилам, применяется только правило с наивысшим приоритетом:

```
1. invites
2. links
3. words
4. caps
5. mentions
6. emojis
7. duplicate
```

---

## Интеграция с белым списком

Пользователи и роли в белом списке сервера обходят все фильтры AutoMod. Управляйте исключениями через интерактивную панель:

```
/whitelist
```

Это полезно для персонала, который может законно публиковать ссылки или приглашения. См. [Справку по белому списку](/commands/whitelist).
