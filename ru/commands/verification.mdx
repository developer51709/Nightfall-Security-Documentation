Группа команд `/verification` настраивает гейт верификации участников. Новые участники должны пройти шаг верификации, прежде чем получить доступ к остальной части сервера.

Когда включена капча, Nightfall отправляет участникам DM с отрисованной капчей — задачей с искажённым текстом. Участники вводят увиденные символы обратно в DM для верификации.

Все команды `/verification` требуют разрешения **Administrator**.

---

## Как это работает

1. Новые участники вступают и не могут получить доступ к полному серверу
2. Они видят канал верификации с постоянной кнопкой **Verify** (опубликованной командой `/verification post`)
3. Нажатие Verify:
   - **Капча ВЫКЛ:** роль назначается немедленно
   - **Капча ВКЛ:** Nightfall отправляет DM‑карточку с инструкциями и изображением капчи
4. Участник вводит 5 символов, которые видит (регистр не учитывается) прямо в DM
5. **Правильный ответ:** DM редактируется на месте, показывая завершённое состояние с наложенной зелёной галочкой; проверенная роль выдаётся
6. **Неправильный ответ:** отправляется карточка ошибки; участник должен снова нажать Verify для получения нового изображения
7. Сессии истекают после **10 минут** бездействия

## Команды

### `/verification panel`

Открыть панель конфигурации администратора.

Показывает текущие настройки и предоставляет:
- Пикер ролей для установки **Verified Role**
- Переключатель **Enable / Disable** для гейта верификации
- Переключатель **Image Captcha: ON / OFF**

---

### `/verification post`

Опубликовать постоянную панель верификации в канале.

| Опция | Тип | Обязательно | Описание |
|--------|------|:--------:|-------------|
| `channel` | TextChannel | ✅ | Канал для публикации кнопки Verify |

**Требования:**
- Сначала должна быть настроена проверенная роль через `/verification panel`
- Nightfall должен иметь разрешение `Send Messages` в целевом канале

Кнопка Verify сохраняется при перезапусках бота — участники могут нажать её в любое время, даже после сбоя.

<Warning>
  Публикуйте панель один раз на канал. Удалите старое сообщение перед публикацией нового.
</Warning>

---

### `/verification reset`

Удалить проверенную роль участника и очистить любую ожидающую сессию капчи, заставляя его снова проходить верификацию.

| Опция | Тип | Обязательно | Описание |
|--------|------|:--------:|-------------|
| `member` | Member | ✅ | Участник для сброса |

**Требуемое разрешение:** Manage Roles

## Формат капчи

| Свойство | Значение |
|----------|-------|
| Размер | 340 × 110 px |
| Длина ответа | 5 символов |
| Набор символов | `A–Z`, `2–9` — без неоднозначных символов (`O`, `0`, `I`, `1`, `l`) |
| Чувствительность к регистру | Нет — принимаются как `a7k2m`, так и `A7K2M` |
| Помехи | Случайные точки шума, 6 пересекающихся линий, размытие по Гауссу |
| Истечение | 10 минут |

---

## Рекомендуемая настройка

1. Создайте канал `#verify-here`
2. Установите разрешения канала:
   - `@everyone` → View Channel ✅ · Send Messages ❌ · все остальные каналы ❌
   - `@Verified` → все каналы ✅
3. Создайте роль `@Verified`
4. Запустите `/verification panel` → задайте роль → включите → включите Image Captcha
5. Запустите `/verification post channel:#verify-here`
6. Переместите роль бота Nightfall **выше** роли `@Verified` в **Настройки сервера → Роли**

---

## Устранение неполадок

| Проблема | Решение |
|---------|-----|
| Участник не получает DM | Он должен включить **Разрешить прямые сообщения от участников сервера** в настройках приватности |
| Кнопка Verify ничего не делает | Убедитесь, что у Nightfall есть `Manage Roles` |
| Не видно других каналов после верификации | Проверьте переопределения разрешений канала для `@everyone` |
| Ошибка «Role no longer exists» | Установите новую роль через `/verification panel` |
| Капча истекла | Участник должен снова нажать Verify для получения нового задания |
