Группа команд `/mod` предоставляет полный набор инструментов модерации с форматированными карточками действий, системой предупреждений с аудит‑следом и автоматическим журналированием модерации.

Все команды модерации требуют соответствующих разрешений Discord. Ответы по умолчанию эфемерные.

---

## Команды

### `/mod ban`

Навсегда забанить участника на сервере.

| Опция | Тип | Обязательно | Описание |
|--------|------|:--------:|-------------|
| `user` | User | ✅ | Участник для бана |
| `reason` | String | — | Причина бана (записывается в журнал аудита и базу предупреждений) |
| `delete_days` | 0–7 | — | Дни истории сообщений для удаления |

**Требуемое разрешение:** Ban Members

---

### `/mod kick`

Удалить участника с сервера. Он может вернуться, если у него есть приглашение.

| Опция | Тип | Обязательно | Описание |
|--------|------|:--------:|-------------|
| `member` | Member | ✅ | Участник для кика |
| `reason` | String | — | Причина кика |

**Требуемое разрешение:** Kick Members

---

### `/mod warn`

Выдать формальное предупреждение участнику. Предупреждения хранятся постоянно для аудит‑следа модерации.

| Опция | Тип | Обязательно | Описание |
|--------|------|:--------:|-------------|
| `member` | Member | ✅ | Участник для предупреждения |
| `reason` | String | ✅ | Причина предупреждения |

Предупреждения включают ID модератора, временную метку и причину. Они никогда не удаляются автоматически.

---

### `/mod timeout`

Временно ограничить участнику отправку сообщений или вход в голосовые каналы.

| Опция | Тип | Обязательно | Описание |
|--------|------|:--------:|-------------|
| `member` | Member | ✅ | Участник для тайм‑аута |
| `duration` | String | ✅ | Продолжительность (например, `10m`, `1h`, `1d`) |
| `reason` | String | — | Причина тайм‑аута |

**Требуемое разрешение:** Moderate Members
**Максимальный тайм‑аут:** 28 дней (лимит Discord)

---

### `/mod history`

Просмотреть историю модерации (предупреждения) участника.

| Опция | Тип | Обязательно | Описание |
|--------|------|:--------:|-------------|
| `member` | Member | ✅ | Участник для просмотра |

Возвращает форматированную карточку со списком всех предупреждений участника на текущем сервере, отсортированных по самым свежим первыми.

---

### `/mod unban`

Отменить бан и разрешить пользователю вернуться.

| Опция | Тип | Обязательно | Описание |
|--------|------|:--------:|-------------|
| `user_id` | String | ✅ | Discord ID забаненного пользователя |
| `reason` | String | — | Причина снятия бана |

**Требуемое разрешение:** Ban Members

---

## Действия из контекстного меню (правый клик)

Правый клик по любому участнику в Discord открывает быстрые действия модерации:

| Действие | Описание |
|--------|-------------|
| **User Info** | Возраст аккаунта, роли, дата вступления и количество предупреждений |
| **Quick Kick** | Открывает модальное окно для подтверждения кика с причиной |
| **Quick Ban** | Открывает модальное окно для подтверждения бана с причиной |
| **Quick Timeout** | Открывает модальное окно для указания продолжительности тайм‑аута и причины |
| **Delete & Warn** | Удаляет целевое сообщение и предупреждает автора |

Эти действия доступны из контекстного меню на любом участнике сервера при условии, что модератор обладает необходимыми разрешениями.

---

## Карточки действий

Каждое действие модерации создаёт стандартизированную карточку ответа:

```
✅  Member Banned
────────────────────────────────
👥  Target:     @username (123456789)
⚖️  Moderator:  @mod (987654321)
✏️  Reason:     Repeated rule violations

─  Nightfall Security  •  Moderation Log
```

---

## Интеграция с логированием

Когда настроен модуль `/logging`, все действия модерации также автоматически публикуются в назначенный канал журнала модерации — дополнительная настройка не требуется.

Инструкции по настройке см. в [Командах логирования](/commands/logging).
