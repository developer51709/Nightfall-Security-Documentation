Группа команд `/security` позволяет администраторам сервера настраивать пороги обнаружения угроз Nightfall, просматривать текущий статус безопасности и включать/отключать защиту.

Все команды `/security` требуют разрешения **Administrator** и доступны только на сервере.

---

## Команды

### `/security config`

Настроить пороги безопасности и канал оповещений для каждой гильдии.

| Опция | Тип | Описание |
|--------|------|-------------|
| `alert_channel` | Channel | Где публикуются оповещения безопасности |
| `max_joins` | 1–1000 | Максимум вступлений участников в минуту до срабатывания оповещения о рейде |
| `max_channel_deletes` | 1–100 | Максимум удалений каналов в минуту до срабатывания оповещения о нюке |
| `max_role_deletes` | 1–100 | Максимум удалений ролей в минуту до срабатывания оповещения о нюке |
| `max_bans` | 1–100 | Максимум банов в минуту до срабатывания оповещения о массовом бане |
| `max_mentions` | 1–100 | Максимум упоминаний в одном сообщении до срабатывания оповещения |
| `min_account_age_days` | 0–365 | Минимальный возраст аккаунта в днях (0 = отключено) |
| `account_age_action` | `kick` \| `ban` \| `alert_only` | Действие для аккаунтов ниже минимального возраста |
| `raid_action` | `alert_only` \| `kick` \| `ban` | Автоматический ответ при обнаружении рейда |
| `nuke_action` | `alert_only` \| `kick` \| `ban` | Автоматический ответ при обнаружении нюка |
| `mass_mention_action` | `alert_only` \| `warn` \| `kick` \| `ban` | Автоматический ответ на массовые упоминания |

Все параметры необязательны — пропуск одного оставляет существующую настройку без изменений.

**Пример:**
```
/security config alert_channel:#alerts max_joins:8 raid_action:kick
```

### `/security overview`

Отображает live‑панель безопасности для текущего сервера, включая:

- Текущие пороги обнаружения для всех типов событий
- Недавние события угроз (последние 10 оповещений)
- Текущие live‑частоты событий (вступления/мин, удаления каналов/мин и т. д.)
- Включён ли Anti‑Nuke
- Статус Premium

---

### `/security toggle`

Включить или отключить защиту Anti‑Nuke от Nightfall для этого сервера.

| Опция | Тип | Описание |
|--------|------|-------------|
| `enabled` | Boolean | `True` для включения, `False` для отключения |

При отключении бот остаётся на сервере и продолжает логирование, но не будет оповещать или предпринимать автоматические действия по событиям нюка или рейда.

## Пресеты порогов

Мастер `/setup` предлагает три пресета в качестве отправной точки:

| Пресет | Вступл./мин | Удаления каналов/мин | Удаления ролей/мин | Баны/мин | Упоминания |
|--------|-----------|--------------------|-----------------|---------|---------| 
| **Strict** | 5 | 2 | 2 | 3 | 5 |
| **Balanced** | 10 | 3 | 3 | 5 | 8 |
| **Relaxed** | 20 | 6 | 6 | 10 | 15 |

---

## Карточки оповещений

Когда порог превышен, Nightfall публикует форматированное оповещение в вашем настроенном канале оповещений:

```
🛡️  Security Alert — ANTI_RAID
────────────────────────────────
Join surge detected: 14 joins in 60 seconds (threshold: 10)

👥  Actor: @username (123456789)
⏰  Detected: 2 minutes ago

─  Nightfall Security  •  Severity: HIGH  •  Defensive mode only
```

### Уровни серьёзности

| Уровень | Значение |
|-------|---------|
| **Low** | Незначительная аномалия — информационно |
| **Medium** | Подозрительная активность |
| **High** | Обнаружена активная угроза |
| **Critical** | Серьёзная скоординированная атака |
