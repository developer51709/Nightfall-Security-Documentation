## Бот не отвечает на команды

<AccordionGroup>
  <Accordion title="Slash‑команды не появляются">
    Discord может занять до **1 часа**, чтобы распространить только что зарегистрированные slash‑команды на всех участников. Попробуйте:

    1. Полностью закройте и заново откройте клиент Discord
    2. Проверьте с помощью `/ping` — если это работает, другие команды должны скоро появиться
    3. Убедитесь, что у Nightfall есть скоуп `applications.commands` (пригласите заново по официальной ссылке, если не уверены)
  </Accordion>

  <Accordion title="Команды появляются, но ничего не делают">
    Проверьте разрешения Nightfall на вашем сервере:

    - Разрешение **Administrator** рекомендуется для полной функциональности
    - Если используются конкретные разрешения, убедитесь, что `Send Messages`, `Embed Links` и `Read Message History` предоставлены в каналах, где используются команды
    - Убедитесь, что роль Nightfall не находится ниже роли, ограничивающей действия бота
  </Accordion>

  <Accordion title="Ошибка 'Missing Permissions'">
    Nightfall нужны конкретные разрешения для конкретных функций:

    | Функция | Требуемое разрешение |
    |---------|-------------------|
    | Оповещения безопасности | `Send Messages` + `Embed Links` в канале оповещений |
    | Определение исполнителя Anti‑Nuke | `View Audit Log` |
    | Действия Kick/ban | `Kick Members` / `Ban Members` |
    | Назначение роли верификации | `Manage Roles` + роль бота выше проверенной роли |
    | Тайм‑аут | `Moderate Members` |
    | Журнал модерации | `Send Messages` + `Embed Links` в канале журнала |
  </Accordion>
</AccordionGroup>

## Оповещения безопасности не срабатывают

<AccordionGroup>
  <Accordion title="Anti‑Raid не оповещает о вступлениях">
    1. Запустите `/security overview` и убедитесь, что anti‑nuke включён
    2. Убедитесь, что установлен канал оповещений (`/security config alert_channel:#your-channel`)
    3. Проверьте порог `max_joins` — если он высокий, небольшая частота вступлений не сработает
    4. Убедитесь, что у Nightfall есть разрешение публиковать в канале оповещений
  </Accordion>

  <Accordion title="Anti‑Nuke не оповещает об удалениях">
    1. Подтвердите, что anti‑nuke включён через `/security overview`
    2. Проверьте пороги `max_channel_deletes` и `max_role_deletes`
    3. Убедитесь, что разрешение `View Audit Log` предоставлено (необходимо для определения исполнителя, но не для самого оповещения)
    4. Доверенные админы, выполняющие массовые операции, могут быть в белом списке — проверьте `/whitelist`
  </Accordion>

  <Accordion title="Оповещение срабатывает, но никаких действий не предпринимается">
    По умолчанию все действия установлены на `alert_only`. Чтобы включить автоматические ответы kick или ban, настройте:

    ```
    /security config raid_action:kick
    /security config nuke_action:kick
    ```
  </Accordion>
</AccordionGroup>

## Проблемы с AutoMod

<AccordionGroup>
  <Accordion title="AutoMod не фильтрует сообщения">
    1. Запустите `/automod status`, чтобы убедиться, что соответствующее правило включено
    2. Проверьте действие правила — `delete` молча удаляет сообщение; `warn` также записывает предупреждение
    3. Убедитесь, что пользователь не в белом списке (`/whitelist`)
    4. Убедитесь, что у Nightfall есть разрешение `Manage Messages` в канале
  </Accordion>

  <Accordion title="Сообщения персонала фильтруются">
    Добавьте роли персонала или конкретных пользователей в белый список — пользователи из белого списка обходят все правила AutoMod:

    ```
    /whitelist
    ```

    Затем используйте **Add Role**, чтобы освободить роль персонала.
  </Accordion>
</AccordionGroup>

## Проблемы с верификацией

<AccordionGroup>
  <Accordion title="Участники не получают DM с капчей">
    У участника, скорее всего, отключены DM. Попросите его:

    1. Открыть **Настройки пользователя → Приватность и безопасность**
    2. Включить **Разрешить прямые сообщения от участников сервера**
    3. Снова нажать **Verify**

    Nightfall не может отправлять DM пользователям, у которых они отключены — это настройка приватности Discord, вне контроля бота.
  </Accordion>

  <Accordion title="Кнопка Verify ничего не делает">
    Убедитесь, что у Nightfall есть разрешение `Manage Roles` на вашем сервере.
  </Accordion>

  <Accordion title="Участники по‑прежнему видят все каналы после верификации">
    Проверьте разрешения каналов:

    - У `@everyone` должно быть **View Channel** запрещено (или не предоставлено) для каналов вне зоны верификации
    - Роли `@Verified` должно быть разрешено **View Channel** для этих каналов
  </Accordion>

  <Accordion title="Бот не может назначить проверенную роль">
    Переместите роль бота Nightfall **выше** проверенной роли в **Настройки сервера → Роли**. Discord разрешает ботам назначать только те роли, которые ниже их высшей роли.
  </Accordion>
</AccordionGroup>

## Проблемы с Premium

<AccordionGroup>
  <Accordion title="Платёж подтверждён, но Premium не активирован">
    1. Убедитесь, что вы нажали **I've Paid — Confirm** в DM‑карточке оформления заказа
    2. Если платёж всё ещё подтверждается в блокчейне, подождите несколько минут и снова нажмите кнопку
    3. Запустите `/premium status`, чтобы проверить текущее состояние подписки
    4. Если счёт показывает **Expired**, создайте новый командой `/premium buy`
  </Accordion>

  <Accordion title="Функции Premium не работают после активации">
    Запустите `/security overview`, чтобы убедиться, что Premium активен для вашего сервера. Если он отображается как активный, но функции не работают, переустановите бота (удалите и пригласите заново) или обратитесь в поддержку.
  </Accordion>
</AccordionGroup>

## Проблемы с журналированием

<AccordionGroup>
  <Accordion title="Журналы не публикуются в назначенный канал">
    Nightfall нужны `View Channel`, `Send Messages` и `Embed Links` в канале журнала. Проверьте:

    1. У роли Nightfall есть эти разрешения в канале (проверьте специфичные для канала переопределения)
    2. Канал существует и не был удалён
    3. Запустите `/logging status`, чтобы убедиться, что назначение всё ещё установлено
  </Accordion>

  <Accordion title="Проверка назначений журналов">
    Запустите `/logging status`, чтобы увидеть все текущие назначения каналов журналов для вашего сервера.

    Используйте `/logging test category:members` (или любую категорию), чтобы опубликовать образец карточки и убедиться, что бот может публиковать там.
  </Accordion>
</AccordionGroup>
