# Affiliate Program

The Nightfall Affiliate Program allows creators, server owners, and community managers to earn rewards when users purchase Premium using their referral code.

## Tiers

### Bronze Tier
- No minimum requirement  
- Track referrals and conversions  

### Gold Tier
- **7 conversions required**  
- Unlocks **instant payouts**  
- Higher commission rate  

## Payouts

- Minimum withdrawal: **$1**  
- Instant payouts for Gold Tier  
- OxaPay crypto withdrawals  

## Commands

- `/affiliate code`
- `/affiliate stats`
- `/affiliate withdraw`
- `/affiliate leaderboard`
