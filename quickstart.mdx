Nightfall Security is designed to be easy to set up while providing professional, multi‑layer protection for Discord communities of all sizes. This quickstart guide will take you from zero to a fully configured Nightfall installation in just a few minutes.

## Prerequisites

Before you begin, ensure you have:

- **Administrator permissions** in the server you want to protect
- A Discord server where Nightfall will be installed
- Basic familiarity with Discord's role and channel system (recommended)

## Get started

<Steps>
  <Step title="Invite Nightfall Security">
    Add Nightfall to your server using the official invite link:

    **[Invite Nightfall Security](https://discord.com/oauth2/authorize?client_id=1528576288938266694)**

    Nightfall requires essential permissions such as managing roles, channels, bans, and message history to provide full protection. Grant all requested permissions for complete coverage.

    <Tip>
      Nightfall's role should be positioned **above** any roles it needs to manage (e.g. your verified member role). You can adjust role order in **Server Settings → Roles**.
    </Tip>
  </Step>

  <Step title="Run the setup wizard">
    Once Nightfall is in your server, start the guided setup process:

    ```
    /setup
    ```

    The wizard will walk you through:

    - **Alert Channel** — where security alerts are posted
    - **Protection Level** — choose Strict, Balanced, or Relaxed thresholds
    - **Anti‑Nuke** — toggle protection against destructive admin actions
    - **Verification** — toggle member entry gate

    Each step includes recommended defaults to ensure strong protection from the start. You can revisit and adjust any setting later.
  </Step>

  <Step title="Verify installation">
    After setup, confirm that Nightfall is active and protecting your server:

    ```
    /security overview
    ```

    This command displays:
    - Active protection systems and their thresholds
    - Recent security alerts
    - Recommended configuration improvements
  </Step>

  <Step title="Configure logging (optional)">
    Set up audit log channels so you have a full record of server activity:

    ```
    /logging set category:members channel:#member-logs
    /logging set category:moderation channel:#mod-audit
    /logging set category:security channel:#security-log
    ```

    See the [Logging command reference](/commands/logging) for all available categories.
  </Step>

  <Step title="Enable verification (optional)">
    Add a member entry gate to block bot raids before they start:

    1. Create a `#verify-here` channel that `@everyone` can see but cannot send messages in, and that hides all other channels
    2. Create a `@Verified` role that grants full server access
    3. Run `/verification panel` to configure the role and enable captcha
    4. Run `/verification post channel:#verify-here` to post the persistent Verify button

    See [Verification](/verification) for full details.
  </Step>
</Steps>

---

## What's protected after setup?

Once the wizard completes, Nightfall is actively monitoring your server for:

| Threat | Protection |
|--------|-----------|
| Mass channel / role deletions | Anti‑Nuke |
| Mass bans by compromised admins | Anti‑Nuke |
| Join surges and bot floods | Anti‑Raid |
| New / suspicious account clusters | Anti‑Raid |
| Spam links and invite ads | AutoMod |
| Mass mentions | AutoMod + Security |
