# Nightfall Security Systems

Nightfall provides multiple independent protection layers designed to keep your community safe from destructive actions, malicious behavior, and unsafe content.

## Anti‑Raid

Nightfall detects coordinated raid patterns such as:

- Mass joins  
- Bot floods  
- High‑velocity join spikes  
- Suspicious account clusters  

Actions include:
- Alerting moderators  
- Auto‑kicking or banning raid accounts  
- Locking channels during active raids  

## Anti‑Nuke

Anti‑Nuke protects your server from destructive admin actions:

- Mass channel deletion  
- Mass role deletion  
- Permission escalations  
- Dangerous configuration changes  

Nightfall automatically intervenes when thresholds are exceeded.

## AutoMod

AutoMod filters unsafe or disruptive content:

- Links  
- Invites  
- Caps  
- Words  
- Emojis  
- Mentions  
- Duplicate messages  

Rules can be customized per guild.

## Verification

Nightfall includes multiple verification modes:

- Button verification  
- Math captcha  
- Account age checks  
- Anti‑alt detection  

Verification helps prevent unauthorized access and bot infiltration.
