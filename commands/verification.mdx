The `/verification` command group configures a member verification gate. New members must complete a verification step before they can access the rest of the server.

When captcha is enabled, Nightfall sends members a DM containing a rendered image captcha — a distorted‑text challenge. Members type the characters they see back into the DM to verify.

All `/verification` commands require the **Administrator** permission.

---

## How it works

1. New members join and cannot access the full server
2. They see a verification channel with a persistent **Verify** button (posted by `/verification post`)
3. Clicking Verify:
   - **Captcha OFF:** role is assigned immediately
   - **Captcha ON:** Nightfall sends a DM card with instructions and a captcha image
4. Member types the 5 characters they see (case‑insensitive) directly into the DM
5. **Correct answer:** the DM is edited in place to show the completed state with a green check‑mark overlay; the verified role is granted
6. **Wrong answer:** an error card is sent; member must click Verify again for a fresh image
7. Sessions expire after **10 minutes** of inactivity

---

## Commands

### `/verification panel`

Open the admin configuration panel.

Shows current settings and provides:
- A role picker to set the **Verified Role**
- **Enable / Disable** toggle for the verification gate
- **Image Captcha: ON / OFF** toggle

---

### `/verification post`

Post the persistent verification panel to a channel.

| Option | Type | Required | Description |
|--------|------|:--------:|-------------|
| `channel` | TextChannel | ✅ | Channel to post the Verify button in |

**Requirements:**
- A verified role must be configured first via `/verification panel`
- Nightfall must have `Send Messages` permission in the target channel

The Verify button persists through bot restarts — members can click it at any time, even after an outage.

<Warning>
  Post the panel once per channel. Delete the old message before posting a new one.
</Warning>

---

### `/verification reset`

Remove a member's verified role and clear any pending captcha session, forcing them to verify again.

| Option | Type | Required | Description |
|--------|------|:--------:|-------------|
| `member` | Member | ✅ | Member to reset |

**Required permission:** Manage Roles

## Captcha format

| Property | Value |
|----------|-------|
| Size | 340 × 110 px |
| Answer length | 5 characters |
| Character set | `A–Z`, `2–9` — no ambiguous characters (`O`, `0`, `I`, `1`, `l`) |
| Case sensitivity | None — `a7k2m` and `A7K2M` are both accepted |
| Interference | Random noise dots, 6 crossing lines, Gaussian blur |
| Expiry | 10 minutes |

---

## Recommended setup

1. Create a `#verify-here` channel
2. Set channel permissions:
   - `@everyone` → View Channel ✅ · Send Messages ❌ · all other channels ❌
   - `@Verified` → all channels ✅
3. Create a `@Verified` role
4. Run `/verification panel` → set the role → enable → turn on Image Captcha
5. Run `/verification post channel:#verify-here`
6. Move Nightfall's bot role **above** the `@Verified` role in **Server Settings → Roles**

---

## Troubleshooting

| Problem | Fix |
|---------|-----|
| Member gets no DM | They must enable **Allow direct messages from server members** in Privacy Settings |
| Verify button does nothing | Ensure Nightfall has `Manage Roles` |
| Can't see other channels after verifying | Review `@everyone` channel permission overrides |
| "Role no longer exists" error | Set a new role via `/verification panel` |
| Captcha expired | Member must click Verify again for a fresh challenge |
