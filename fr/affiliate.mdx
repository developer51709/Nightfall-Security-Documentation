Le programme d'affiliation Nightfall permet aux partenaires approuvés de gagner de la reconnaissance et des avantages en recommandant des serveurs Discord au palier premium du bot. Les affiliés partagent un code unique ; chaque serveur qui utilise ce code démarre un essai gratuit de 7 jours, et les serveurs qui passent à Premium payant sont comptabilisés dans le palier de l'affilié.

---

## Fonctionnement

<Steps>
  <Step title="Obtenez votre code">
    Les codes d'affiliation sont délivrés par les administrateurs du bot Nightfall. Une fois approuvé, vous recevez un code unique à partager.
  </Step>

  <Step title="Partagez votre code">
    Partagez votre code avec les administrateurs de serveurs Discord. Ils l'utilisent avec :

    ```
    /premium redeem code:VOTRE-CODE-AFFILIE
    ```
  </Step>

  <Step title="L'essai s'active">
    Le serveur reçoit immédiatement un **essai gratuit de 7 jours** de Nightfall Premium. Chaque serveur ne peut utiliser qu'un seul essai d'affiliation.
  </Step>

  <Step title="Suivez les conversions">
    Surveillez vos essais, conversions et la progression de votre palier avec `/affiliate stats`.
  </Step>

  <Step title="Gagnez des avantages">
    À mesure que vos conversions s'accumulent, vous progressez à travers les paliers et débloquez de la reconnaissance, un support prioritaire et l'éligibilité aux paiements.
  </Step>
</Steps>

## Système de paliers

| Palier | Conversions requises | Éligible au paiement | Avantages |
|--------|---------------------|:--------------------:|-----------|
| **Partner** | 0 | ❌ | Commencez le suivi — partagez votre code et générez des conversions |
| **Bronze** | 1+ | ❌ | Badge d'affilié dans `/affiliate stats` |
| **Silver** | 3+ | ❌ | Mention en support prioritaire + analyses personnalisées |
| **Gold** | 7+ | ✅ | Éligibilité au partage de revenus + portefeuille de paiement + support prioritaire |
| **Diamond** | 15+ | ✅ | Éligibilité à la mise en avant des partenaires + tous les avantages Gold |

Les paliers sont calculés en direct à partir de votre nombre de conversions — aucune attribution manuelle de palier n'est nécessaire.

## Analyses

Consultez votre tableau de bord d'analyses complet avec :

```
/affiliate stats
```

| Indicateur | Description |
|------------|-------------|
| Essais totaux | Guildes ayant utilisé votre code |
| Essais actifs | Essais actuellement en cours |
| Conversions en attente | Essais expirés, remise envoyée, en attente d'achat |
| Conversions | Guildes ayant acheté Premium après l'essai |
| Taux de conversion | `conversions ÷ essais_totaux × 100` |

---

## Système de paiement

Les affiliés de **palier Gold ou supérieur** (7+ conversions) peuvent enregistrer un portefeuille crypto pour les paiements.

```
/affiliate payout
```

Utilisez le bouton **Set / Update Wallet** dans le panneau pour saisir votre adresse de portefeuille et votre réseau. Les réseaux pris en charge incluent Bitcoin (BTC), Ethereum (ETH), Solana (SOL), USDT‑TRC20, USDT‑ERC20, USDC‑ERC20, Litecoin (LTC), et d'autres.

Les paiements sont traités par l'équipe Nightfall selon un calendrier glissant pour les affiliés éligibles.

---

## Remise post‑essai

Lorsqu'un essai expire sans que le serveur ne passe à Premium payant, Nightfall envoie automatiquement au propriétaire du serveur un **DM unique** avec une offre de remise (20 % de réduction sur le premier mois). Si le propriétaire du serveur effectue un achat par la suite, une conversion est créditée à votre compte.

## Devenir affilié

Les codes d'affiliation sont délivrés par les administrateurs enregistrés du bot Nightfall. Pour postuler :

1. Rejoignez le [serveur de support officiel](https://discord.gg/CXzX38Z7J9)
2. Contactez l'équipe pour manifester votre intérêt
3. Si vous êtes approuvé, votre code est activé immédiatement
4. Atteignez le **palier Gold** (7+ conversions) pour débloquer l'enregistrement du paiement

## Règles

- **Représentation précise** — les affiliés doivent représenter Nightfall et l'offre d'essai avec honnêteté. Toute promotion trompeuse ou mensongère est interdite.
- **Aucune activité frauduleuse** — la création de fausses utilisations d'essai, la coordination de fausses conversions, ou toute autre fraude d'affiliation entraîne un retrait immédiat et l'annulation des avantages en attente.
- **Propriété du code** — les codes d'affiliation restent la propriété des administrateurs du bot Nightfall et peuvent être révoqués à tout moment.
